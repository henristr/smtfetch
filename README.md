## Installation

### Linux

```bash
curl -fsSL https://raw.githubusercontent.com/henristr/smtfetch/main/install.sh | bash
```

### Nix

Install the latest version directly from GitHub:

```bash
nix profile install github:henristr/smtfetch
```

Run it without installing:

```bash
nix run github:henristr/smtfetch
```

### Windows

```powershell
irm https://raw.githubusercontent.com/henristr/smtfetch/main/install.ps1 | iex
```
